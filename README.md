# Grid-Connected Power Converters — Operating Principles (NPTEL)

Simulation notebooks accompanying the NPTEL course **"Grid-Connected Power Converters - Operating Principles"**.

## About

This repository contains Jupyter notebooks used to build up an understanding of grid-connected power converter operation, progressing tutorial by tutorial from simple switching-pole models to full converter topologies.

**Note:** These are simplified, educational models and not detailed circuit-level models like those obtained from SPICE-type simulators. They are intended to be useful for building intuition and models for power system studies, not for detailed converter design or hardware validation.

## Tutorials

| Tutorial | Topic | Status |

Each tutorial folder has its own README with details on the notebooks it contains and how to run them.
